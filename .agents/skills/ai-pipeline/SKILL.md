# AI Pipeline Skill

Required prototype models:
1. U-Net or Mask R-CNN for building segmentation.
2. Random Forest or XGBoost for a defined labelled attribute task.
3. Isolation Forest for anomaly detection.

For every model define:
- task
- inputs
- labels
- split
- metric
- baseline
- error analysis

No fabricated metrics.

Stop if labels or evaluation data are insufficient.
