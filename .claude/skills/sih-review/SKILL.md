# SIH Review Skill

Review the implementation against SIH26011.

Check that the prototype addresses:
- surface parcels
- multi-storey properties
- vertical representation
- underground representation where supported
- DEM/DSM interface
- building extraction
- floor/vertical mapping
- topology validation
- interoperability/provenance

Reject unsupported claims such as:
- official 3D ULPIN issuance
- exact floors from DSM
- AI ownership adjudication
- 100% accuracy
- fabricated government datasets

Every requirement must map to a demoable module or an explicitly documented limitation.
