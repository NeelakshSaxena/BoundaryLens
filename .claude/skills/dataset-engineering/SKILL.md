# Dataset Engineering Skill

## Goal
Discover, ingest and document geospatial datasets reproducibly.

## Required steps
1. Confirm source and licence.
2. Record acquisition date.
3. Inspect CRS and schema.
4. Record coverage/resolution.
5. Save raw input unchanged.
6. Generate manifest and checksum.
7. Create a processed copy only through scripted transformations.

## Verification
A dataset is usable only when source, licence, CRS, schema and coverage are known.

## Stop
Stop for unknown licence, unknown CRS, corrupt data or unsupported attributes.
